P가 지급 조건에 서명하기

100 MTK를 B에게 지급합니다. B가 등록한 때부터 2분 동안 잠기며, 등록 후 10분에 전체 지급이 완료됩니다.

이 화면에서 하는 일은 메시지 서명까지입니다. 토큰 approve와 일정 등록은 이후 각각 별도 거래로 진행합니다.

1. 제공자 지갑 연결

MetaMask가 설치된 Chrome에서 Sepolia와 P 계정을 선택하세요.

2. 서명할 조건 확인

미사용 번호를 입력하세요. 조회한 블록 시각에서 한 시간 뒤를 등록 마감으로 잡습니다. 조건 확인 버튼을 다시 누르면 마감도 새로 정합니다.

MetaMask에 전달할 전체 데이터

  





  
3. MetaMask에서 직접 서명

  
표시된 계약·P·B·금액·기간·마감을 확인한 뒤 요청하세요. 서명은 이 지급 조건에 대한 승인입니다. 아직 사용하지 않은 서명 파일은 B에게 전달하고 공개 저장소에는 올리지 마세요.

  
  



지갑 연결을 기다립니다. 서명·거래는 아직 실행하지 않았습니다.
